##Penjelasan singkat
Sistem pengelolaan cuaca, pengguna akan memasukkan data suhu untuk mengetaahui suhu tersebut masuk ke dalam kategori cuaca apa.

##Flowcart
<img width="890" height="733" alt="image" src="https://github.com/user-attachments/assets/66475c42-6db8-460d-aa14-905758849214" />
Program dimulai dari start atau mulai, lalu pengguna melakukan input untuk memilih akses sebagai admin atau user. jika login sebagai admin berhasil, sistem akan menampilkaan menu admin 1-4:
1. memasukkan suhu dengan mengecek nilai
   apakah suhu <= 22 derajat. jika iya maka akan mencetak "cuaca dingin"
   apakah suhu <= 23-25 derajat. jika iya maka akan mencetak "cuaca sejuk"
    apakah suhu <= 26-29 derajat. jika iya maka akan mencetak "cuaca hangat"
    apakah suhu <= 30-34 derajat. jika iya maka akan mencetak "cuaca panas"
    apakah suhu <= 35-40 derajat. jika iya maka akan mencetak "cuaca terik"
    lainnya apakah suhu > 40 jika iya maka akan mencetak "suhu ekstrem"
   jika tidak maka akan lanjut ke menu ke dua
2. Menghapus suhu dengan menjaalankan proses penghapusan data suhu
3. mengubah suhu dengan menjalankan proses perbaikan atau pengubahan suhu
4. keluar dengan mengakhiri sesi admin

Jika login sebagai user berhasil, sistem akan menampilkan menu user 1-2:
1. tampilkan data cuaca: menampilkan daftar data cuaca yang tersimpan
2. keluar: mengakhiri sesi user
